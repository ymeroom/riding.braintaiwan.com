容量：X3 5.7K 約 50 GB／小時，GO 3S 2.7K 約 20–30 GB／小時。兩台合計每天錄 1 小時，19 天約 1.3 TB。

回家後

  • X3 360° 素材先用 Insta360 Studio 匯出等距長方 MP4（不調角度），再請 Claude 用 ffmpeg 轉固定視角。
  • GO 3S 若是 .mp4 可直接剪；若是 .insv，同樣先用 Studio 匯出。
  • 給 Claude 的資料：兩台素材資料夾＋Garmin 的 FIT／GPX＋口述標記。成品 2.7K 或 1080p、30fps。
  • 在自己電腦上的 Claude Code 剪（素材太大，不適合雲端 session），可用 daily-film 技能做精華配樂。
雙機同時開錄時，拍一下手或講「同步」，Claude 可以用聲音波形對齊兩台。
